# personal-site

Yuren Cheng's personal homepage, deployed to yuren.dev.

- Vite + React + TypeScript, single static page
- Style modelled on jakub.kr: single centred column, name, intro, social icons, project list
- Faint background inspired by nasana's `glowingMarblingBlack` on Shadertoy (WtdXR8), slowed to ~0.22x, rendered at half resolution, blurred and veiled in white so it stays in the background
- No articles, no newsletter

Deploy: Cloudflare Workers Static Assets (`wrangler.toml`, `personal-site` worker), custom domain yuren.dev.
